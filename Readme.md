# Description

OS ini dibuat untuk hobi dan dokumentasi sebagai sarana bahwa developernya sudah
mempelajari low-level programming dengan lancar, dan target sistem operasi ini
adalah performanya yang setara atau melebihi sistem operasi linux Cachy-os yang
membawa konsep kernel scheduler bore, memory management yaitu ram swap, dan masih
banyak lagi yang akan diimplementasikan pada kernel dust ini, saya Devnnw12 membuat 
kernel ini dengan architecture hybrid dengan meniru structur kernel milik windows
yang bernama 'ntoskrnl' yang isinya sama persis tetapi saya membuatnya agak sedikit
berbeda, walaupun terlihat sama.

# Target sistem operasi 

Target yang saya tuju adalah membuat os ini menjadi alternative dari windows yang
berat dan tidak stabil secara performa mentah. 

Inilah list yang saya tuju ketika os ini
jadi dan digunakan pada banyak orang:

``````
1. tanpa telemetry yang dapat memberikan
   rasa tidak nyaman terhadap privasi atau
   keamanan.

2. performa mentah yang dapat meningkatkan
   kenyamanan dalam bermain game atau bekerja
   seperti editing, simulasi, rendering 3d.

3. system memory yang dirancang sangat cerdas
   dalam menangani ram yang sedikit ataupun
   system ram swap yang langsung dilevel hardware
   dengan memanipulasi ram atau storage. 
``````
