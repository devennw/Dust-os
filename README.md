# DUST
sistem operasi berbasis non linux atau tanpa basis dari windows atau FreeBSD.
sistem operasi ini menawarkan performa mentah yang bagus atau lebih pada
windows, kernel yang digunakan pada Dust ini berbasis kernel nt yang ditulis
dari nol, driver yang akan disupport pada Dust ini akan banyak atau setara dengan
windows 11.

OS ini akan dikembangkan setidaknya 10-15 tahun untuk awal pembuatan, dikarenakan 
yang mengembangkan sistem operasi ini hanya sendirian dan tidaklah mudah bagi
os-dev sendirian, terinspirasi dari Thery Davis yang mengembangkan sistem operasinya
sedirian.

# RENCANA AWAL
awalnya Dust akan dibuat pada ekosistem arm chip untuk handphone dan desktop
namun semakin lama developer Dust sadar kalau windows sudah tidak ramah bagi
pengguna device desktop low-end, windows memakan ram yang sangat tinggi bahkan
pada ram 4gb yang terpakai 3.0gb memory ram dengan ram yang kecil akan sulit
menggunakan desktop pada penggunaan browsing yang membutuhkan banyak tab.

pada akhirnya Dust dipindahkan pada ekosistem desktop dan akan mendatang untuk
ekosistem arm pada desktop. pengembangan awal seharusnya dikerjakan pada tim
khusus yang hanya mengerjakan Dust namun pengembangan Dust hanya dapat dikerjakan
sendiri karena masalah keuangan yang tidak stabil.

KEUNTUNGAN
-----


| PERFORMANCE YANG AKAN DITAWARKAN ADALAH: |
|------------------------------------------|
- fps pada stress test selama 2 jam akan distabilkan pada tingkat 
  os yang membuatnya menjadi unggul dalam gaming maupun server yang
  menjaga asset penting.

- tanpa telemetry yang dapat membuat performance pada device menurun
  atau privasi yang dapat dilihat pada developer.

- Graphic Api yang sangat stabil. graphic api ini menyediakan perfomance
  pada gpu secara hardware yang membuatnya menjadi ungul dalam stabilisasi
  graphic api.
   
   Contoh:
   * Game yang akan dimainkan memerlukan performa lebih untuk rendering 
     texture, map, dan shader yang digunakan pada game yang akan dimainkan
     tersebut.

   * dapat membantu device low-end untuk meminimalisir lag pada game
     akan dimainkan dan scheduler cpu yang sangat baik dalam game yang
     membutuhkan fps tinggi.

   * pc server yang membutuhkan rendering untuk pembuatan video film
     atau endering 3d film dan animasi yang berat, yang akan meringankan
     proses yang sangat berat untuk pc server.

- security yang aman yang menggunakan cryptography milik Dust yang akan
  mengamankan data-data penting dengan penggunaan ram sebesar 50mb.
  security ini akan mengamankan folder penting yaitu folder sys yang berisi
  folder-folder penting seperti kernel, driver, graphic api, firmware dan
  lain-lain, ini juga akan mengamankan akun, device, dan akan memaksa virus
  komputer yang berbahaya dihapus sampai tak tersisa.

- GUI yang dapat diricing seperti distro linux, dan pilihan gui yang banyak
  seperti kde plasma, gnome, dan masih banyak lagi yang dapat diricing, ricing
  ini akan terpasang dengan sendirinya pada akun Dust kalian.
