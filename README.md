# Dust os

Dust os adalah os dengan fokus pada performa kernelnya walaupun masih sangat
rentang sekali untuk di gunakan, walaupun begitu saya Devnnw akan berusaha 
semaksimal mungkin agar kernel ini dapat bekerja sampai ketitik dimana kernel
milik windows memiliki jarak fps pada game cyberpunk 2077 sekitaran 14 fps.
walau terdengar mustahil, tetapi ini adalah project bejalan saya sejak umur 14
tahun pada tahun 2026.
